# Temporary experiment-design issue list (delete before finishing)

Scope: baseline fairness, metric validity, hypothesis discipline. Each item is
implemented in code, self-checked, and committed separately.

1. [x] Count-model floor tunes and reports on the SAME full validation rows,
       while the neural panel uses a nested chronological holdout. The floor's
       smoothing sees the evaluation documents, so the "beats floor" comparison
       is selection-biased. Fix: nested selection/holdout for the simple
       baseline, record row fingerprints, and require the floor and panel to
       score the same rows and token denominator.
2. [x] The floor comparison is a pointwise `panel_ppl < floor_ppl` with no
       uncertainty. Fix: seed-level paired delta versus the deterministic floor,
       exact sign-flip p/CI, and a verdict that distinguishes a significant
       win from an apparent win within seed noise.
3. [x] The declared tuning grid is coarse (2 learning-rate levels) and the
       audit cannot tell when the selected config sits on the grid boundary
       (i.e. the search range is too narrow). Fix: broaden the declared grid,
       then add a grid-coverage/boundary adequacy audit with warnings.
4. [ ] Open-block panel declares factors (max block length, open-block reading
       rule) but has no pre-registered hypothesis (statement/mechanism/sign/
       falsifier) checked by the same hypothesis audit. Fix if time permits.
