# Temporary bug list (delete before finishing)

- [ ] audit_efficiency_pairs truncates fractional `n_tokens` with `int()`, so
      1.5 and 1.0 look like the same shape and can permit a false speed claim.
      Parse exact token counts and refuse malformed/ambiguous ones.
- [ ] audit_selection does not reject non-finite/out-of-range per-seed
      mass/baseline rows; such rows are silently dropped by the exact test
      while `n_seeds` still counts them, hiding a malformed artifact.
- [ ] audit_boundary accepts precision/random-baseline readings outside [0,1]
      and can print "exceeds baseline" from an impossible measurement.
- [ ] scaling_trend marks a trend significant from p<alpha even when the
      per-seed slopes are within seed noise (|mean|<=std), contradicting the
      shared claim contract.
- [ ] audit_length compares `truncated is False` by identity, so a direct
      caller's `np.bool_(False)` bypasses the n_tok==n_seq*(L-1) check.
- [ ] archive_release `--out` accepts absolute/`..` paths and writes the
      archive outside the repository (the tag and packed dirs are guarded).
