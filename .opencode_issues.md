# Temporary experiment-design issue list

Scope: baseline adequacy, metric contracts, and hypothesis alignment. Delete
after the fixes are committed.

1. **Baseline tuning audit trusts the artifact's selection direction.**
   `baseline_tuning_audit` reads `direction` from the artifact and validates
   only that it is one of the two known strings. An artifact can declare
   `higher_is_better`, select the *maximum* PPL trial, and pass, even though
   the declared protocol says PPL is lower-is-better. The audit must bind the
   direction to the protocol (and to the PPL semantic) before checking the
   argmin.
2. **Audit field fallbacks turn an explicitly malformed value into the
   protocol default.** Both baseline audits use `artifact.get(key) or
   protocol.get(key)`, so an empty string / explicit `false` is silently
   replaced by the declared valid value instead of being reported.
3. **The count-model floor can be chosen from an undeclared arm.** The simple
   baseline audit checks missing declared arms but not extra arms; an extra
   arm can become `best_baseline` and the quoted tuned floor, outside the
   declared equal-search design.
4. **Trivial-floor reproduction accepts non-count supports.** The metric audit
   validates `trivial_baseline` by `int(support)`, which truncates fractional
   values and accepts booleans, so a forged support can reproduce the
   supposed majority-class floor.
5. **A record can claim its recommended primary endpoint is available while
   omitting it.** `metric_policy_audit` verifies the recommended metric name
   but not the `recommended_primary_available` claim against the actual
   recorded endpoint.
