# Temporary data-method issue list (not a report)

1. `split_and_prepare(quality_report=True)` records a `fail` quality report but
   still returns data. A caller can fit a model on a split with label noise /
   NaN / material shift without noticing. Add a strict quality gate that raises.
2. `clean_training_rows` cannot remove training rows with non-finite features
   or train-only outliers; outliers are only clipped at transform time and no
   cleaning record is produced. Add train-only non-finite/outlier row cleaning.
3. `data_quality_report` audits feature outliers but not regression-target
   outliers. Add a train-reference target-outlier audit (never using holdouts).
4. The v12 one-shot test access runs `audit_leakage` but not the split-discipline
   gate, so train/test distribution shift and exact row overlap are not required
   before the frozen test evaluation. Gate P5T on both audits.
