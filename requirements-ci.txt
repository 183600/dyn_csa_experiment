# CI-only entry point into the verified environment (CPU, Python 3.12).
#
# This file used to repeat only the five direct dependencies.  CI then
# resolved its own transitive closure and could install a different stack
# than the local reproduction environment, so a green test run did not prove
# that the locked environment passes.  Install the lock itself instead: the
# lock is the single environment contract (including the +cpu torch wheel
# selected by its --extra-index-url) and exp_lib.dependency_contract()
# verifies the interpreter/platform clauses it declares.
#
#   - continuous-loop.yml installs this file once for the test gate;
#   - test.yml uses it as the setup-python cache key (cache-dependency-path).
#
# 安装方式（CPU wheel）：
#   python -m pip install -r requirements-ci.txt \
#     --extra-index-url https://download.pytorch.org/whl/cpu
#
# Do not add direct pins here: a second list would silently drift from the
# lock again.  Update requirements.lock (then regenerate it on the target
# machine) and both local reproduction and CI move together.
-r requirements.lock
